# Path Finder Visualizer

A Python-based visualizer that demonstrates how pathfinding algorithms explore a grid to find a path between a starting point and a destination.

## 📌 Project Overview

Path Finder Visualizer provides a visual way to understand how pathfinding algorithms work. Users can interact with a grid, set start and end points, add obstacles, and observe how an algorithm searches for a route.

This project was built to improve my understanding of Python, algorithms, and problem-solving.

## ✨ Features

- Interactive grid-based visualization
- Set a starting point and destination
- Add obstacles to the grid
- Visualize the algorithm's exploration process
- Display the resulting path when one is found

## 🛠️ Tech Stack

- Language: Python
- Library: Pygame
- Concepts: Pathfinding algorithms, priority queues, graph traversal, and grid-based search

## ⚙️ Installation and Setup

1. Clone the repository
```
git clone https://github.com/Shripadcoder/Path_Finder-Visualizer.git
```

2. Navigate to the project folder
```
cd Path_Finder-Visualizer
```

3. Install the dependency
```
python -m pip install pygame
```

4. Run the project
Find the main Python file in the project folder and run it. For example, if the file is named `main.py`:
```
python main.py
```
Replace `main.py` with your actual filename if it is different.

## 🚀 How to Use

1. Run the Python program.
2. Select the starting point and destination according to the controls implemented in the project.
3. Add obstacles to the grid.
4. Start the visualization.
5. Observe how the algorithm explores the grid and finds a path, if one exists.

Refer to the code for the exact mouse and keyboard controls.
